# Rubric policy

**These are editable examples, not verified school policy.** Confirm each track rubric with an instructor before using for official grades. The `core-25.json` template mirrors a prior 5 × 5 framework with a provisional 18/25 threshold (72%). Track rubrics use a proposed 100-point framework and a provisional threshold of 72%; thresholds must be approved centrally before any student outcomes.

For production, create `rubrics/<track>/week-01.json` ... `week-06.json` tied to that week's actual assignment specification, review/version each rubric and lock versions used for historical grading. Do not compare unlike rubric versions without normalization and instructor consent.
